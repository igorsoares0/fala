# Caption fonts

The four caption faces, shared by the editor preview (`next/font/local` in
`apps/web/app/layout.tsx`) and the export renderer (`apps/worker/src/media/overlay.ts`),
so both draw captions with the same font binaries.

Source: [google/fonts](https://github.com/google/fonts) (`ofl/…`), converted to WOFF2
without other changes. All are licensed under the SIL Open Font License 1.1
(see `OFL-*.txt`), which allows commercial use and embedding in rendered videos.
